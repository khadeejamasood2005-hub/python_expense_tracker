# python_expense_tracker
Python Expense Tracker

Project Description

A simple desktop Expense Tracker application developed using Python and Tkinter. It allows users to record, categorize, delete and track their daily expenses. Expense records are automatically stored in a CSV file.

Features

* Add expenses with description, category and amount.
* Categorize expenses into Food, Travel, Shopping, Bills and Other.
* View expense records in a table.
* Automatically calculate total expenses.
* Delete selected expenses.
* Clear all expense records.
* Automatically save data using CSV file storage.

Technologies Used

* Python
* Tkinter
* CSV

How to Run

1. Install Python.
2. Download or clone the repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run:

python expense_tracker.py

Project Files

* expense_tracker.py – main Python application.
* expenses.csv – automatically stores expense records.
